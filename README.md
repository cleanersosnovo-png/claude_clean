# 💰 Финтрек — учёт и оптимизация личных расходов

Мобильное приложение (PWA) для учёта расходов и доходов, контроля бюджета и поиска
способов сэкономить. Работает **офлайн**, устанавливается на телефон как обычное
приложение, **не требует сервера и регистрации** — все данные хранятся только на
вашем устройстве (в браузере).

## Возможности

**Учёт**
- Быстрое добавление расходов и доходов в пару касаний
- 12 категорий расходов и 5 категорий доходов с иконками
- Комментарии и произвольная дата операции
- Редактирование и удаление, поиск и фильтр по категориям
- Переключение между месяцами

**Оптимизация**
- Общий месячный бюджет и лимиты по каждой категории
- Прогресс расходования бюджета в реальном времени
- Прогноз трат к концу месяца по текущему темпу
- Норма сбережений (доходы − расходы)

**Аналитика**
- Кольцевая диаграмма расходов по категориям
- Динамика трат за 6 месяцев
- Автоматические советы: рост/снижение трат, превышение лимитов,
  самая «дорогая» категория, частые перекусы и т.д.

**Данные**
- Экспорт и импорт в JSON (резервная копия / перенос между устройствами)
- Полная очистка данных
- Валюты: ₽, $, €, ₸, Br

## Как запустить

Приложению нужен любой статический веб-сервер (из-за Service Worker его не открыть
просто как `file://`).

```bash
# из корня проекта
python3 -m http.server 8080
# затем откройте http://localhost:8080 в браузере
```

## Установка на телефон

1. Откройте сайт приложения в мобильном браузере (Chrome / Safari).
2. **Android (Chrome):** меню ⋮ → «Установить приложение» / «Добавить на главный экран».
3. **iOS (Safari):** «Поделиться» → «На экран "Домой"».
4. Значок появится на рабочем столе — приложение открывается в полный экран
   и работает без интернета.

## Развёртывание

Это статический сайт — его можно бесплатно опубликовать на GitHub Pages, Netlify,
Vercel или Cloudflare Pages. Просто загрузите содержимое репозитория; точка входа —
`index.html`.

> Для корректной работы PWA (Service Worker) нужен HTTPS — все перечисленные хостинги
> предоставляют его автоматически.

## Технологии

Чистый HTML + CSS + JavaScript, без фреймворков и внешних зависимостей.
Графики нарисованы вручную на SVG. Хранение — `localStorage`. Офлайн — Service Worker.

## Структура

```
index.html              — разметка и экраны
css/styles.css          — стили, светлая и тёмная темы
js/store.js             — данные, категории, localStorage
js/charts.js            — SVG-диаграммы
js/app.js               — логика интерфейса и аналитика
manifest.webmanifest    — манифест PWA
sw.js                   — Service Worker (офлайн)
icons/                  — иконки приложения
```

## Приватность

Приложение не отправляет данные никуда. Всё, что вы вводите, остаётся в памяти
вашего браузера. Хотите перенести на другое устройство — используйте экспорт/импорт.

При первом запуске добавляется несколько демонстрационных операций, чтобы показать,
как всё выглядит. Их можно удалить кнопкой «Очистить все данные» в разделе «Бюджет».
